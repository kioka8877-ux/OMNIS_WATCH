## Architecture à connaître

### Pipeline DELTA (le travail en cours)
```
delta/
  F00_INGEST        → téléchargement/découpe vidéo
  F04_TIMING        → timing JSON (words, segments)
  F05_PREVIEW       → ⭐ PREVIEW = source de vérité du style (Vite + React)
  F06_RENDER        → rendu Remotion (F03A_REMOTION) + merge_codex.py
```

### Fiche principale : `delta/F05_PREVIEW/src/App.jsx`
Toute la config se fait dans cette preview. Points clés :
- `updateField(path, value)` (ligne ~196) : **merge profond** si la valeur est un objet
  (ne remplace plus l'objet entier — c'était le bug des presets qui écrasaient tout).
- `buildSegments(timing)` : regroupe les mots en phrases (max 8 mots ou ponctuation finale).
- Rendu sous-titres + titre dans le même IIFE (segment partagé).
- `getTitleFromTiming(style, timing)` : le titre ne s'affiche que si le JSON a un titre.
- Bouton export → télécharge `codex_STYLE.json` (= style pour TOUS les clips).

### Fiche : `delta/F06_RENDER/CODEBASE/merge_codex.py`
Fusionne `codex_STYLE.json` (IN) + `timing_XXX.json` (IN) → `codex_clip_XXX.json` (OUT).
- Utilise `text_defaults.animation` comme **type** d'animation (cohérent avec la preview).
- Titre = `timing.title` ou `style.title` → overlay `role:"title"` avec fond si activé.
- Glow/depth annulés si fond de titre actif.

### Rendu final : `delta/F06_RENDER/F03A_REMOTION/CODEBASE/src/components/OmniComposition.jsx`
- Lit `codexData` importé (`src/codexData.js` généré par le merge).
- `TextOverlay` : anime mot par mot / fade / pop selon `overlay.animation`.
- Fond (pill) désactivé pour les sous-titres, réservé au titre.
